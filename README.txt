LEAN MARQUEZ - PERSONAL WEBSITE
===============================
Open index.html in any browser (double-click it). No installation needed.

FILES
  index.html   - the page structure (Home, About Me, Services, Legends, Gallery, Contact)
  style.css    - colors, fonts, layout, animations (dark / light mode too)
  script.js    - slideshow, gallery, typing effect, dark mode, contact form
  fonts/       - fonts used by the site (works offline)
  images/      - put your photo + drawings here (see images/README.txt); images/projects/ holds your web project screenshots

THINGS TO EDIT
  script.js  line 6      MY_EMAIL     -> your real email (contact form uses it)
  script.js  ROLES       -> the words that type in the hero
  script.js  SOCIALS     -> your Facebook / Instagram / Viber / WhatsApp / TikTok links (contact section)
  script.js  PROJECTS    -> your web projects and screenshot list
  script.js  LEGENDS     -> add / remove F1 and MotoGP legends, change text and stats
  script.js  DRAWINGS    -> your drawing titles and file names
  index.html             -> About Me text and Services text
