PUT YOUR OWN PICTURES HERE
==========================
images/hero.png                   -> cut-out photo on the Home section (transparent PNG looks best)
images/about.jpg                  -> photo in the About Me section
images/drawings/drawing-1.jpg ... drawing-6.jpg  -> your drawings (Work Gallery)
images/legends/*.jpg              -> legend photos (names are in script.js, "photo:" fields)
images/projects/*.jpg             -> screenshots of your web projects (list: PROJECTS in script.js)

If a file is missing, the website shows a built-in placeholder instead,
so nothing breaks. Just drop the files in with the same names.
